# Ecommerce-spring

Ce TP s'inscrit dans le cadre de la formation sur les microservices avec Spring Boot. Il permet
de mettre en pratique les concepts vus en cours (MVC, JPA, JWT) à travers le développement
d'une application e-commerce.

### Objectifs Pédagogiques
1. Comprendre l'architecture MVC dans Spring Boot
2. Maîtriser la persistance des données avec JPA
3. Implémenter des API REST
4. Gérer la sécurité des données
5. Mettre en place des tests

### Prérequis
1. Java 17
2. IDE (Spring Tool Suite ou IntelliJ IDEA)
3. MySQL
4. Git
5. Postman
6. Structure du TP

Partie 1 : Configuration et Setup

1. Configuration de l'environnement
2. Structure du projet
3. Configuration de la base de données
4. Mise en place des entités

Partie 2 : Développement des Fonctionnalités Core (3h30)

1. Implémentation des DTOs
2. Développement des Services
3. Création des Controllers
4. Tests unitaires

Partie 3 : Sécurité et Tests (3h30)

1. Implémentation de la sécurité
2. Gestion des exceptions
3. Tests d'intégration
4. Documentation API

Partie 4 : Finalisation et Déploiement (3h30)

1. Optimisation des performances
2. Logging et Monitoring
3. Préparation au déploiement
4. Revue de code
